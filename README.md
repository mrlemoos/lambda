# Lambda (ƛ)

Lambda is screenwriting software built around the [Fountain](https://fountain.io) markup format.

The editor uses [TipTap](https://tiptap.dev). It began with [React Fountain](https://github.com/mrlemoos/react-fountain), an experiment in bringing TipTap and Fountain together in one editor.

This is a love letter to screenwriting, an art I think is having a rough time of it.

I fell in love with storytelling at eight. Now I write screenplays and pay the bills with software engineering.
