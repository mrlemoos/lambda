# ADR 0015: Collaboration v1 is comments, cursors, and presence

**Collaboration** on a **Stored script** ships all three in v1: range comments, live cursors, and presence (who is in the document). Yjs text sync alone is not the SKU. TipTap + Yjs awareness for cursors/presence; comment threads anchored to a document range.
